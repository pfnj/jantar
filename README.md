# Organizador de Jantar (Ponto Médio)

Aplicação web local (HTML + CSS + JavaScript) para organizar jantares de grupo em Portugal.

## Funcionalidades
- **Recolha de participantes:** Adiciona nomes com **Cidade/Concelho** e **Localidade/Zona** (opcional).
- **Raio de pesquisa ajustável:** Escolhe entre 500 m, 1 km, 1,5 km, 3 km, 5 km ou 10 km ao redor do ponto médio.
- **Mapa Interativo:** Visualiza os participantes (azul), o ponto médio e o círculo do raio de pesquisa (vermelho) e os restaurantes encontrados (verde).
- **Orçamento / Preço Médio e Classificações:** Define ou filtra por nível de preço (`€` a `€€€€`), edita avaliações manualmente ou usa uma chave opcional da **Foursquare Places API** para obter notas e preços automaticamente.
- **Sugestões Manuais:** Adiciona restaurantes sugeridos pelo grupo fora dos resultados automáticos.
- **Guardar e Partilhar Sessão:** Guarda automaticamente no navegador (`localStorage`) e permite **Exportar/Importar JSON** para partilhar a votação com outras pessoas, além de copiar o resumo para o WhatsApp ou descarregar em `.txt`.

## Como utilizar
1. Extrai todos os ficheiros deste ZIP para uma pasta.
2. Faz duplo clique no ficheiro `index.html` para abrir no teu navegador.
